# Experiment 001 — Leave a Trace

## Purpose

Learn the most important GitHub idea: a project can change while its earlier states remain remembered.

## The experiment

Edit this file directly on GitHub.

Under **My first trace**, add one sentence beginning with:

> Today I am curious about...

Then choose **Commit changes**. A commit is simply a named checkpoint in the history of the laboratory.
