# Experiment 002 — Trembling Spores

**Date:** 2026-09-03  
**State:** alive and misbehaving

## The spark

My first encounter with creative coding through p5.js.

Instead of copying and pasting the example, I typed it by hand. Changing a few numbers immediately changed the visual behaviour—and that small act felt surprisingly good.

## What it does

The sketch follows the cursor, but introduces randomness into:

- horizontal position
- vertical position
- circle size
- transparency

The result resembles trembling spores, spectral dust, or evidence recovered shortly before a Victorian investigator's unexplained disappearance.

## What I discovered

Code can behave like an artistic material. A number is not merely information: it can become distance, scale, colour, speed, density, or uncertainty.

I did not place every circle. I made a small system that placed them.

## Files

- `index.html` — loads the p5.js library and the sketch
- `sketch.js` — contains the drawing behaviour

## Next mutations

Possible things to change one at a time:

- the range of the trembling
- the minimum and maximum circle sizes
- the colour and transparency
- circles into another shape
- whether the old marks remain or disappear

## Result

**Delightfully successful.** The basic mechanism was simple, but changing it created an immediate feeling of authorship.
