# The Whimsical Laboratory 🗝️

A cabinet of creative experiments, curious technologies, strange ideas, and possible future worlds.

This is not a productivity system and nothing here needs to become a Serious Project™. It is a place to notice interesting things, follow peculiar connections, and make small experiments before deciding what deserves a larger life.

## Rooms

- [Idea Cabinet](ideas/README.md) — fragments, questions, and suspicious little possibilities
- [Experiment Table](experiments/README.md) — things currently being tried
- [Field Notes](discoveries/README.md) — useful, beautiful, or wonderfully strange findings
- [Specimen Drawer](templates/idea-seed.md) — a reusable page for capturing a new idea

## Current experiment

[Experiment 001: Leave a Trace](experiments/001-leave-a-trace.md)

The first experiment is intentionally tiny. Its purpose is to make GitHub feel less like software infrastructure and more like a notebook with an unusually good memory.

## Laboratory rules

1. Curiosity is sufficient justification.
2. Small experiments count.
3. Abandoned ideas are evidence, not failures.
4. Understanding may arrive after making.
5. No one is required to monetise the haunted object.
