# Idea Cabinet

Fragments live here before anyone demands that they become plans.

Possible specimens:

- a strange question
- a visual image that will not leave
- an object that ought to exist
- two unrelated ideas that may secretly know each other
- a project with no practical justification whatsoever

When one becomes interesting, copy the [idea-seed template](../templates/idea-seed.md) into this room and rename it.
